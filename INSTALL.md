# Installation and testing

Bench-test from a current-limited 5 V supply before vehicle wiring. Confirm camera, SD, Wi-Fi/NTP and Telegram paths. With the ultrasonic generator disconnected, verify GPIO43 is LOW at boot and changes only for a qualified test. Test the external power stage with a dummy load and hardware cutoff.

After Edge Impulse integration, test held-out images, then run supervised engine-bay trials. Validate temperature, brownout, watchdog recovery, fuse behavior and EMI before unattended use. Ultrasonic effectiveness is experimental and must be assessed without harming animals.
